# Better Auth Aurora DSQL Adapter

Amazon Aurora DSQL adapter for [Better Auth](https://www.better-auth.com).

## Installation

```bash
npm install @better-auth/dsql-adapter
```

## Documentation

For full documentation, visit [better-auth.com/docs/adapters/postgresql#amazon-aurora-dsql](https://www.better-auth.com/docs/adapters/postgresql#amazon-aurora-dsql).
